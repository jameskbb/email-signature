# Signature editor

Mode: Operate. Build directly in code. The signature layout is fixed: image, vertical rule, identity and optional contact rows.

Use a quiet stationery workspace: warm off-white page, dark ink, restrained green actions, white email preview. A compact header leads to an editor on the left and a sticky preview on the right. On mobile the preview follows the form with a visible jump link. Use native labeled fields, generous group spacing, and visible focus. The signature itself uses Arial for email portability. No decorative illustration or external font request. Success is an immediately understandable form and a copyable signature.

Examples are labeled as examples. Empty fields disappear. URL validation, storage failure, image load failure, and clipboard denial get clear recovery messages. Exported markup must escape user text and reject unsafe URL schemes.
