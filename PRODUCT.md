# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Static HTML, CSS, and JavaScript with GitHub Pages support. No runtime dependencies or build step.

## Users

People creating a personal or professional email signature.

## Product Purpose

Generate a signature with an image on the left, a solid vertical divider, then name, position, and company. Optional phone, email, and social or website links appear underneath the identity.

## Operating Context

Run locally or on GitHub Pages. Copy the rendered signature into an email client's signature settings or download HTML.

## Capabilities and Constraints

Live preview, optional contact fields and arbitrary labeled links, hosted image URL, local draft persistence, and email-compatible table markup with inline styles. No account, backend, telemetry, or build toolchain. Email clients may modify pasted formatting or block remote images.

## Product Principles

- Keep signature creation fast and understandable.
- Omit empty optional fields.
- Keep personal details in the browser.
- Keep the app portable to static hosting.
